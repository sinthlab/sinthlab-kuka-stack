Cue settings and tests

Each task sets the ring's brightness when it starts and when it is changed (visual_cue.brightness, 0.02 by default; Live under All settings). Every task colour is at full value, so that one setting sets how bright every cue and the reward are. A brightness applied here lasts until the next run starts, or the board restarts unless saved on the board.

The board has no brightness limit. Colour cues above about 0.3 can exceed the capacity of the end effector’s 5 V converter. See the POWER note in end_effector_metro_code/code.py.

LED-by-LED test

The test lights each LED in red, green, blue, and white. If an LED stays dark, note the pixel number below. The ring has four sections of 15 LEDs (0–14, 15–29, 30–44, and 45–59).
